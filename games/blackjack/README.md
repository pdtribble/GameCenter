# Blackjack

Standard single-deck blackjack. Each player competes against the dealer.

## Rules
- Hit or Stand each turn
- Dealer hits on ≤16, stands on 17+
- Natural blackjack (21 on first 2 cards) beats dealer's 21

## Settings
- `botDifficulty`: `'easy'` | `'medium'` | `'hard'` (default: `'medium'`)

## Players
- Min: 1, Max: 7 (plus dealer)
