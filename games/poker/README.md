# Texas Hold'em Poker

No-limit Texas Hold'em. Players compete for the pot using hole cards + community cards.

## Rules
- Pre-flop, Flop, Turn, River betting rounds
- Actions: Check, Call, Raise, Fold
- Best 5-card hand wins

## Settings
- `smallBlind`: number (default: 10)
- `bigBlind`: number (default: 20)
- `startingChips`: number (default: 1000)
- `botDifficulty`: `'easy'` | `'medium'` | `'hard'`

## Players
- Min: 2, Max: 8
